# How start the app so the code runs
## Activate the virtual environment
```
 source fast_venv/bin/activate
 cd fast_cities
 ls
 fastapi dev main.py
```
You will see errors in the terminal, because `config.py` is missing in the `fast_cities` directory
There is a stub file called `test_config.py`, follow the instructions

## Important note
REMEMBER TO CHANGE THE NAME FROM `test_config.py` to `config.py` so that hashed passwords are stored
